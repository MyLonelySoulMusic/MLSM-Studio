# Cassette Desk mechanical audio

`cassette-action-cc0.mp3` is the public preview of **cassette tape action
2.wav**, a field recording by Freesound user **cognito perceptu**. It contains
the cassette insertion, deck-door movement and mechanical button action used by
the Cassette Desk intro.

- Source: https://freesound.org/people/cognito%20perceptu/sounds/98329/
- Preview file: https://cdn.freesound.org/previews/98/98329_57789-lq.mp3
- License: Creative Commons Zero 1.0 (CC0)
- License text: https://creativecommons.org/publicdomain/zero/1.0/

The application crops the relevant movements at runtime and layers a very quiet,
deterministic procedural reinforcement underneath them. The same rendered PCM
is used by preview and offline export.
