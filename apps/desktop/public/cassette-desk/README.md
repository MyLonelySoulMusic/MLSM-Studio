# Cassette Desk visual assets

`window-environments-v1.png` is an original project asset generated with the
built-in OpenAI ImageGen tool. It contains seven equal horizontal crops in this
order:

1. summer day;
2. snow day;
3. night;
4. rain night;
5. starry night with a white moon;
6. night with a pink moon;
7. night with a pink meteor.

The source prompt requested the same camera, skyline and neighborhood geometry
across all seven panels, with no interior, people, text, logos or window frame.
The renderer supplies the window geometry, glass, weather motion and indoor
reflections so preview and offline export remain deterministic.
